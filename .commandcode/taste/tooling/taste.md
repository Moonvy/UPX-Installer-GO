# Tooling

- Prefers native UI over WebView-based desktop interfaces: for the MyGo desktop app the UI must be Go code drawn natively, with the whole web frontend (React, Vite, `package.json`, `node_modules`, HTML) deleted rather than kept alongside — no Node/Bun/npm in the toolchain. Confidence: 0.75
- Habitually uses npm scripts as the task-runner interface (`npm run dev` / `build` / `test` / `release`) and wants that muscle memory preserved even in projects with no Node/Bun dependencies — a dependency-free `package.json` acting purely as a command shortcut for the real toolchain (`go tool mygo …`) is acceptable and preferred. Confidence: 0.75
- Prefers modern native window chrome over the OS default: frameless / hidden title bar (view draws its own title bar, reserving the space the OS window controls need) plus a vibrancy material (macOS `NSVisualEffectView` / Windows 11 Mica) with translucent panels, falling back to an opaque background where no material exists. The material should be kept restrained: draws a dark semi-transparent scrim over it (and retunes panel colors onto it) so the desktop behind only tints the window instead of showing through. Confidence: 0.6
- Values a single source of truth for app metadata: the app version lives in one config file (`mygo.json`) and is read from there, instead of being duplicated or kept in sync by a script. Confidence: 0.6
